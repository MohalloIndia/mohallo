# Mohallo Design System — V2

## Composition

Use 60–30–10:
- 60% neutral canvas
- 30% secondary surfaces/text/navigation
- 10% accent/actions

## Visual direction

Prefer:
- white / warm-neutral foundation
- strong dark typography
- disciplined accent usage
- subtle borders
- light elevation
- high-quality spacing

Use the existing Mohallo accent as the source of truth where practical.

## Layout

- max content width around 1200–1280px
- generous section rhythm
- 12-column desktop grid
- 4-column tablet grid where useful
- 1-column mobile

## Typography

Strong display heading
Clear section heading
Readable body
Compact supporting metadata

Avoid excessively heavy typography across every element.

## Buttons

Primary:
accent filled

Secondary:
neutral/outline

Tertiary:
text

## Forms

- visible labels
- helper text only when useful
- validation below field
- clear required indicators
- password visibility control where appropriate
- preserve values between steps

## Stepper

The seller onboarding stepper should have:
- numbered step
- title
- completed state
- active state
- clear current position

Desktop:
horizontal

Mobile:
compact progress header

## Cards

Use cards for:
- plans
- shop previews
- actionable dashboard tasks

Do not card-wrap every paragraph.

## Motion

Keep motion subtle.

The loader is exempt because it is locked and must remain unchanged.
